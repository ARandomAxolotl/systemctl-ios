# systemctl-ios

> a systemctl-like wrapper for launchctl

## Supported environments :

- iOS (jailbroken)

## Tested environments :

- My jailbroken iPhone 8 Plus

## Installation :

Download the script.

Run it (`chmod +x` if required).

Move it to a directory in `PATH` if you want to, such as `/usr/local/bin/`.

## Dependencies :

- launchctl

- zsh

- jailbreak
